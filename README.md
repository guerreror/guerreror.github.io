# guerreror.github.io

Website for the Guerrero Lab (Department of Biological Sciences, NC State University), built on the [al-folio](https://github.com/alshedivat/al-folio) v1.x Jekyll starter.

## Local development

```bash
bundle install
bundle exec jekyll serve --baseurl /al-folio
```

The site is served at `http://localhost:4000/al-folio/`.

## Repository layout

See [AGENTS.md](AGENTS.md) for how this repository is organized (thin starter vs. gem-owned runtime), the validated local command set, and where to route changes. [`docs/`](docs) has longer-form architecture and contributor notes inherited from the al-folio starter.
